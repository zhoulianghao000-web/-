## 恢复与范围

发布/业务/SMS 失败均有限自动重试，DEAD 在数据库保留且报警，超过自动重试预算后需要管理员重放；broker 恢复不自动把 DEAD 无限循环重新发布。DLQ 转发记录也可恢复，原业务已 PROCESSED 时不重新执行。OTP 过期不能重放复活，用户需要重新申请验证码。畸形消息保留在隔离 DLQ，需检查和修复发送方，不开放任意原始 payload 的重放 API。

本批证明数据库业务动作幂等。短信供应商属于外部系统：正式适配必须支持 challenge ID 幂等键或查询不确定结果；供应商尚未接入，本批使用符合该契约的测试网关和本地文件替身，不能据此声称已验证生产短信的 exactly-once。实测 broker 为单节点应用级停启，未进行多节点容灾演练。

新增模型与恢复语义见 [投递模型](M2.2-投递模型.md) 和 [ADR-0029](adr/0029-outbox-inbox-and-external-effects.md)。V001/V002 未修改，V003 与 database/migrations 镜像一致。下一阶段按计划进入 M2.3 存储/搜索适配，M2.4 前端工程仍待实施。
