# V3.1.3-B1 模拟条款、报价与名额预占

执行日期：2026-10-20。状态：本地验证中，完整 CI 尚未通过；V3 总验收、最终 APK 和桌面整体包均未交付。

## 实现边界

- V030 新增 service_trade_terms、service_trade_quotes、service_trade_orders，不改写旧免费预约及履约事实；当前只有未付款交易、取消和到期，不创建支付/退款/结算。
- 商家显式提交金额、整时段计价、取消界线、佣金、结算缓冲及 TEST_SCENARIO 依据，独立 service.terms.write 权限。平台 service.terms.review 权限与同名动作的一次性二次验证审核；新审核条款取代旧条款，旧报价失效，已创建交易快照保留。
- 消费者条款只含实际展示内容；内部佣金、结算和依据及内部摘要不进入消费者条款、交易或商家订单列表。客户端只提交服务端报价和已读摘要，不能传入金额或付款成功。
- 报价至多 5 分钟且不晚于时段开始，不占名额。订单预占至多 10 分钟且不晚于时段开始。此为工程演练技术窗口，不能当作真实商家规则。已用报价不可重复建单；幂等重放仍核验归属、身份、门店权限。
- 新旧预约统一时段锁和容量；数据库触发器再守护容量、同用户重复占位、报价与订单快照一致性及不可变事实。消费者取消与定时到期释放预占；审计和业务状态在同一事务。B2 加入支付后必须扩展关闭查询边界，UNKNOWN 不得按本地超时释放。
- 两个模拟开关均需显式开启，默认关闭，生产 deployment-mode/profile 均拒绝，试点暂停时拒绝。B1 不开放付款按钮；页面与完整模拟交易在 B3 合并验收。商家和平台只交付 Web，消费者安卓唯一。
