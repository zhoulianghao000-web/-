# V1 智能选品与测试登录安装说明

本批为 1.0.9-engineering，消费者 Android / Web 为 0.6.14+20。仅本地模拟环境，生产条件继续留白。

## 进入方式

- 双击桌面 PawdayV1，打开本地入口。消费者网页为 http://127.0.0.1:4175 ，商家为 http://127.0.0.1:4273 ，管理员为 http://127.0.0.1:4174 。
- 消费者网页与 Android 统一使用用户指定的一个测试账号和密码。打开“查看测试账号”可在本机私有窗口查看；不再申请或刷新模拟短信验证码。
- 账号密码保存在当前 Windows 用户的 `%LOCALAPPDATA%/PawdayV1/consumer-test-login.clixml`，使用 DPAPI 加密，源码及开发 ZIP 不含该私有文件。迁移到另一台电脑时，首次启动会要求配置本机测试账号密码。
- 商家、管理员账号与权限保留。消费者测试账号映射到首个既有模拟消费者，保留其宠物等资料；其他模拟消费者的数据不删除，但在单账号模式下不能继续使用其会话。

## Android 更新

安装 `Pawday-Consumer-0.6.14-test-login-debug.apk`。本批采用固定内部测试签名，与此前临时签名不同；如果系统提示签名冲突，需要先卸载手机上的旧测试版再安装。本地 App 会话会被清除，电脑数据库中的原账号资料保留。此后本机交付链沿用该内部测试签名。生产签名未配置。

通过 USB 测试时保持电脑服务启动与 USB 调试连接，双击桌面“Pawday安卓连接”；它会配置 adb reverse 8086。App 中输入本机指定账号与密码即可，也可使用右上角“跳过”进入游客首页。

## 本批界面

消费者首页的猫咪入口改为“智能选品”，在右下角固定，位于底部导航上方，点击进入现有 AI 选品流程。商家、管理员工作台及桌面入口打开消费者选品页，不传递员工令牌。原有参考图片保留。

原生 Android 模拟版登录页去除与“跳过”重复的关闭按钮；标题、跳过及表单上移。当前环境仅模拟 AI 和交易，点击入口不会自动发起外部 AI 请求。

## 数据和验收边界

更新不会重建数据库或清除 `.pilot`。报告及哈希以同目录交付验证 JSON 为准。本批自动化 Android Widget 测试与 APK 构建通过不等同新 APK 已在用户手机上实测。14 项生产证据、运营通知继续留白，生产总验收未关闭。
