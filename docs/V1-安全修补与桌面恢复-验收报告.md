# Pawday V1 安全修补与桌面恢复验收报告

日期：2026-10-13。交付版本：1.0.7-engineering。受测代码：`63f48e158e7025a683421ce8b741b5a84ff9bc0c`，分支`codex/pawday-v1-security-fixes`。

**结论：本轮发现的问题已修补并通过工程复验，桌面启动恢复，九个同提交CI门禁通过。** 只审查已经实现的V1功能；用户确认留白的生产资料、渠道及运营通知不纳入补齐。未将此次安全维护记为V1全部功能完成或生产上线批准。

## 桌面故障与修复

现场复现：4172入口进程存在，后端不健康，Docker Desktop引擎返回无法启动；原脚本因此直接抛错，快捷方式窗口随之结束。恢复Docker引擎后，WSL版本查询和四服务重新健康；未重装、重置或删除Docker数据。

启动脚本新增Docker启动等待、按本交付进程记录恢复半启动状态、复用经过归属核验的专用容器、互斥锁及可见失败提示。进程身份比较改为UTC时间点，兼容PowerShell5.1/7的JSON时间类型，拒绝复用PID和外部交付进程。快捷方式指向正式`launch-desktop.ps1`，成功后打开本机入口，失败时显示原因。

另修复RabbitMQ持久化身份缺口：此前容器重建会使用随机hostname；现在首次升级记录并保留原节点hostname，以后保持稳定。无法核验旧数据节点时明确拒绝，避免静默创建空节点。专用持久消息已经跨镜像升级和容器重建验证保留。
