# PawdayV1 网页动效修订启动说明

版本：1.0.2-engineering。本机模拟工程环境，需先启动 Docker Desktop。

1. 使用桌面 PawdayV1 图标，或解压完整开发包后双击「启动PawdayV1.cmd」。
2. 打开 http://127.0.0.1:4172，选择商家、管理员或消费者入口。原页面已打开时按 Ctrl+F5。
3. 双击项目内「查看测试账号.cmd」：管理员 local-admin，商家 local-staff-a / local-staff-b；密码从本机窗口读取。
4. 消费者在 http://127.0.0.1:4175 使用 +999000000001 至 +999000000020。在用户端申请验证码，再切回测试账号窗口点击 Refresh local SMS codes，填写最新一条六位验证码。该窗口可关闭后重新打开刷新。
5. 敏感业务操作保留密码二次验证。使用「停止PawdayV1.cmd」停止本项目服务，测试数据保留。

网页新增短入场、切页和操作反馈；系统开启减少动态效果时自动禁用位移。消费者 Flutter / APK 沿用 0.6.8+14，未新增 GSAP。

源码开发：pnpm install --frozen-lockfile；pnpm lint；pnpm typecheck；pnpm test；pnpm build。pnpm build 会同时输出 desktop/dist/motion.js。开发包已包含构建文件，不需要先安装 npm 依赖即可本地启动。GSAP 与所有字体资源均本地加载。

14 项生产资料保持空白与待补，M6 生产总验收未关闭。
