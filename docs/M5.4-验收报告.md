## 交付行为

- 复用 merchant_store 与当前授权，不复制商家身份。新增资料含城市、宠物店/医院/美容洗护/寄养类别、GPS WGS84 坐标、地址、电话、营业信息与可用服务；来源明确为商家提交。没有虚构真实门店、高德 POI 同步或无主外部地点认领交易。
- 商家只能读写获授权门店资料。创建 If-Match 为 0，修改检查当前版本且重新进入 DRAFT / UNREVIEWED / 未认证。管理员需 nearby.read + nearby.moderate、一次性二次验证、TOTP 与审核依据来发布、隐藏、核实/拒绝认领和认证；公开/认证必须已核实认领。认证与商家身份分开，审核历史不可覆盖或删除。
- 事实、版本、审核、审计与 NearbyStoreChanged Outbox 同一 PostgreSQL 事务提交。相同键重试不重复事件，变更内容复用键冲突；并发修改只允许一个版本胜出。审计/Outbox 写入失败回滚事实与验证证明。事件只带 store_id/version，durable quorum 队列确认后才标已发布。
- 游客可按城市、类别浏览，城市模式 distance_m=null、稳定 UUID 排序；主动定位后查询约 10 km，服务端按同一 WGS84 球面直线距离/UUID 排序、分页。半径、坐标系、页大小和 offset 有边界。附近直接读取 PostgreSQL 当前公开事实；草稿、隐藏及商家停用立即不可查询或生成新导航意图，MQ 重复投递不会影响结果。
- 消费者进入附近页不触发位置授权。主动选择才检查服务/权限，允许粗粒度位置；拒绝、永久拒绝、服务关闭、超时和不可用可继续按城市浏览。位置只在页面内存与本次查询使用，不写事实表、审计或 Outbox，不申请后台位置/连续轨迹。迟到结果不能覆盖新城市。
- 门店详情展示地址、电话、营业信息、可用服务、来源及认领/认证状态，可进入既有门店客服，登录保留入口。可用服务并不表示在线预约名额，医院只提供地点/服务/联系方式，不给诊断、疗效排名或治疗建议。
- NavigationProvider 只接受当前公开门店引用。AMAP_URI 生成固定官方 HTTPS marker URI，正确编码目的地与 `coordinate=wgs84`，不接受用户 URL/起点或客户端坐标。客户端检查目的地一致性和 scheme/host/path/参数，失败尝试网页后备，再失败给手动搜索提示。高德页面负责选择出行方式与导航，Pawday 不计算路线。服务端可关闭 provider；三端不嵌生产 SDK 密钥。依据：[高德官方地点 URI](https://lbs.amap.com/api/uri-api/guide/mobile-web/point)。
