# V2.2 家庭共享与照顾协作

基线：V2.1 已验收代码 4562ebe，交付提交 07487fa。实施日期：2026-10-14。

共享以一只宠物为边界。主人保留所有权、档案编辑、删除、照片和原有购物/AI上下文；成员只在独立“家庭照顾”页面选择当前宠物。共享不会把成员加入主人的订单、地址、支付、客服、余粮通知或AI授权。VIEWER可查看明确授权的宠物档案及照顾记录，CAREGIVER另可新增/完成照顾任务和写日常记录，不能改健康档案或删除宠物。主人可以撤销成员，成员可以退出；权限每次请求从数据库检查，不放进长期token。

主人签发一次性随机邀请凭证，24小时有效，最多5个未过期邀请、20名有效成员。凭证不含手机号，不通过真实短信发送；需已登录消费者主动接受，首个接受者绑定身份，主人不能接受自己的邀请。数据库只保存散列及供幂等恢复的加密凭证；凭证不进入日志、审计、URL或交付包。邀请可撤销，失效/已撤销不能接受；撤销成员同时关闭尚未使用的邀请，防止旧链接恢复权限。

授权与所有共享写命令统一先锁宠物、再检查成员及版本；撤销与成员写操作串行，撤销提交后的请求即时拒绝，包括旧幂等key。任务用If-Match乐观锁，终态不可覆盖；日常记录追加且不提供编辑删除接口。记录保留来源用户ID、时间及审计元数据，不记录真实联系方式。照顾日志为日常观察，不提供诊断建议。档案仍由主人维护，照片不在本阶段共享，以避免把私人媒体访问授权扩散。

单测试账号保留，人工可测试主人创建/撤销邀请、任务和记录；跨成员接受、退出、撤销、冲突和其他私密领域越权使用独立自动化账号。未增加公众注册、多个可人工登录的测试账号或外部调用。共享上下文只在页面内保存，登出/身份变化/权限失效即清空，不保存到持久层。

硬门槛：真实PostgreSQL验证迁移、邀请并发接受、过期/撤销、角色边界、任务版本冲突、幂等、撤销后缓存重放拒绝、审计失败事务回滚、跨域隔离；OpenAPI可验证及生成一致；消费者Web/Android UI加载/空状态/重试/窄屏；现有九个CI job及完整基础设施健康；交付开发包、源码、同签名APK、报告和验证JSON。14项生产证据及运营通知继续留白。
