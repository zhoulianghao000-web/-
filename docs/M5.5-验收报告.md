## 已交付与验收结论

1. 真实 DeepSeek HTTP 适配器、JSON evidence plan 白名单、完整正文超时/64 KiB 上限和工具隔离；模型只整理 PostgreSQL 中已发布且可售 SKU 的证据。最多三个规格、明确预算筛选、确定性冲突/信息不足始终显示。供应商不接收个人身份、宠物姓名/备注、原始问题或会话历史。
2. RESERVED→CONSUMED/RELEASED 不可覆盖账本、用户行锁并发约束和请求键唯一。预占先提交再调用 HTTP；结果与扣次同事务。故障释放、durable lease 恢复、迟到回包隔离、持久化失败回滚通过。
3. 已付款会员额度按购买周期快照和期限逐笔冻结；月度 20、年度 300 不能按天重置，续费不能借用未来期。普通上海日额度、会员日安全上限可后台版本化配置，免费余额优先，分别展示余额。
4. 个性化默认关闭、归属校验；会话加密、主动清除/到期擦除密文和宠物关联。明确绝育建议显示差异并显式接受/拒绝；接受需当前宠物版本一致，模型不能自动保存。
5. 管理员提示/策略/评估/历史不可覆盖；RBAC、一次性 reverify、同事务 audit、If-Match、稳定用户灰度、已发布版本回滚。验证页标注为确定性边界验证，不冒充模型效果评测。
6. Flutter 登录 returnTo、当前宠物、授权、发送/历史/清除/差异确认与迟到 UI 隔离；管理员 Vue 配置/验证/灰度/回滚；商家 Vue 资料维护说明且无消费者会话权限。303 个已实现 API 操作，本阶段新增 22 个，TS/Dart 生成一致性通过。

实现细节及能力收窄边界见 [实现设计](M5.5-实现设计.md)，启动与凭证配置见 [启动说明](M5.5-启动说明.md)。

## 修正与边界

本地验收修正审计测试字段名、Dart 关键字 `case`→`case_code`、YAML 1.1 的 YES/NO 字符串引用，以及误加入五 Tab 分支的重复 AI 路由；收尾补充登录身份切换清除聊天回归，修正真实浏览器测试遗漏登录同意步骤，以及 Flutter Web 合成 fill 未保留手机号的输入事件问题，改为聚焦后真实键盘输入并校验字段/同意状态及短信 HTTP 响应；同类城市输入步骤也统一等待焦点渲染、全选替换并检查实际查询；三份已完成的失败 artifact、截图/trace 与原因已保留，失败结果未计入最终通过。最终门禁只针对上述最终受测提交。

未提供生产 DeepSeek 密钥；**真实云端推理、模型效果、限流和费用尚未验收**。当前实现为严格证据整理，非开放医疗问答；任意档案字段自动解析、AI 客服接管及通用规则编辑不记作已完成。正式支付/退款/代付、物流、短信/云存储、iOS 签名和实体机、恢复/容量等仍在 M6。M5 工程通过仅允许进入生产准入准备，不代表产品可以上线。
