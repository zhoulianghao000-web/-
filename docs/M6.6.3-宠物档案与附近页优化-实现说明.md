# 宠物档案与附近页优化

2026-10-12；范围为现有消费者 Flutter App/Web，延续参考页面的纸白、绿色、圆角与交互动效。

## 宠物档案

- 档案页最大宽度 1200；桌面 3 列、平板 2 列、手机 1 列，卡片圆角 24、间距 24。空状态提供本地原参考照片、添加入口和三项真实功能提示。
- 照片卡片使用真实用户上传的 AVATAR 引用；缺图/加载失败显示品牌底色与爪印。下部遮罩强化白字对比，姓名最多两行、品种一行；底部操作使用独立纸白区域，避免按钮直接压在照片上。
- 表单分为基本信息、年龄状态、过敏忌口；字段间距 20，窄屏双列改为单列。过敏原名称、状态、来源分层展示；未知不被解释成无过敏。
- 品种可按物种搜索平台词典，也可选择常见名称或自行填写。常见名称是录入便利项，以 `custom_breed_name` 按主人填写保存，不创建虚假的平台品种 ID，不参与品种鉴定或医疗规则。更换物种清空原品种。
- 生日、估算年龄、暂不填写互斥。生日支持日期选择和空格、斜杠、中文日期粘贴；严格校验日历日期后提交 ISO 日期，拒绝未来及溢出日期。估算年龄分年/月输入，卡片展示完整日历月计算的“岁/月”，估算显示“约”。

## 上传和持久化

复用现有上传凭证、5 MiB 上限、JPEG/PNG、魔数/尺寸/哈希验证和本地对象存储。V023 仅为 pets 增加 `photo_asset_id`、`custom_breed_name` 两个可空字段；旧档案无须重建。上传、读取、绑定均保持消费者所有权边界；绑定使用 media 行共享锁，与删除互斥；已被活动宠物引用的资源不可删除。更换/移除后可删除未引用资源。取消表单及成功保存时尽力清理本次未使用上传；网络失败可能保留未引用的自有资源，不影响档案事实。

OpenAPI 3.1 现行工程契约为 `openapi/pawday-m6.6.3.yaml`，生成 TypeScript/Dart DTO，保留历史契约独立校验。实际宠物 HTTP 响应使用现行契约验证。隐私结构盘点增加两个字段，保留策略、外部面、删除授权仍待审核，14 项生产资料继续留白。

## 附近

标题、查询卡、结果和测试工具分区。城市/类别在宽屏并排、窄屏纵排；城市快捷项、查询/定位按钮和隐私提示各自留出间距。结果卡展示类别、地址、直线距离和服务，整卡可操作且保留按钮语义。模拟定位和导航异常收进“测试场景工具”，继续验证授权、拒绝、服务关闭和导航失败，模拟模式不调用外部导航。

保留普通模式的真实定位分支；进入附近页不会主动索取定位。已有异步请求代次隔离、城市回退、分页、客服和目的地 provider 行为保持。
