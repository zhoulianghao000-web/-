# Pawday V1 功能收尾测试说明

本机工程模拟版，消费者 0.6.11+17，交付 1.0.5-engineering。尚不能投入真实经营。

双击桌面 PawdayV1 图标，等待本机服务健康后进入消费者、商家或管理员。原有测试账号和密码保留，仍在本机测试账号窗口查看，不写入公共交付包。网页使用 Ctrl+F5 获取最新构建。

- 消费者：宠物 → 当前粮 → 记录包装重量、每日实际用量和日期 → 保存 → 校准实际余量/停止。开启提醒后，在预设时间窗内通过站内消息查看；点击后仍需自行确认是否购买。
- 消费者：商品详情 → 收藏商品；附近门店详情 → 收藏门店；我的 → 我的收藏 → 查看/取消。下架或隐藏内容显示已不可用。
- 消费者：已模拟付款订单 → 子订单 → 申请发票，填写测试抬头和 test@example.invalid 等测试邮箱。我的 → 发票申请查看商家处理状态。拒绝后可从原订单修正重提。
- 商家：发票申请 → 查看本人已授权范围申请 → 填写受理/拒绝说明 → 确认账号密码进行二次验证。当前只验证申请处理，不开具真实税务发票、不发送邮件。
- 管理员：发票申请查询；审计记录查看申请/受理/私密抬头读取等动作。管理员不能代替商家开票。

当前界面继续使用用户指定的参考原图、奶油底/深绿视觉、圆角卡片和按钮反馈。补购不会自动下单/扣款，输入用量不是喂食建议。

工程数据和凭据保存在专用 .pilot 目录。升级前备份、兼容迁移 V024；不要把私有 .pilot、测试短信、用户上传资料或数据库放入源码/开发包。开发包带运行时和构建结果；源码包用于开发，不含数据库和凭据。

14项生产资料仍留白；真实交易、税务开票、正式短信/AI/存储/地图、实机与生产容量不在本批通过声明内。V1剩余功能差距见 V1-原始需求收尾复核.md。
