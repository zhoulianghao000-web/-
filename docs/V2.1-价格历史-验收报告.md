# V2.1 价格历史验收报告

日期：2026-10-14。版本：2.0.1-engineering；消费者Web/Android：2.0.1+21。受测代码：`4562ebe7aaa9aced765d6985d3b7c5034c958efe`。

## 本批实现

- V026建立追加式`offer_price_snapshots`。报价创建、售价/会员价和销售状态变化由PostgreSQL触发器在原事务中记录；业务回滚时记录一起回滚，原幂等命令重复执行不增造事实。
- 现有报价只建立迁移时的采集基线。历史不使用报价原始创建日期或当前价格伪造。记录追加后不能UPDATE、DELETE或TRUNCATE；不存在业务写历史接口。
- 保存记录时的公开标记。消费者只查询当前仍可公开的Offer，且历史私有报价、状态与记录时间被遮蔽；商品后来重新发布，不反向开放当时的私有改价。商家需原报价读取权限及商户/门店范围，管理员需原管理员报价读取权限。
- 四个正式查询契约支持30/90个上海日历日，返回每日最后已记录报价和真实依据时间。未知/未公开日期留空，普通和会员标价分开，缺口不连线，最低/最高明确限定为已记录日末普通报价。不表示历史库存、成交、运费、优惠券或结账实付。
- 消费者Web/Android在商品商家报价下打开“查看价格记录”，支持范围切换、重试、曲线及逐日记录。商家/管理员在“报价与库存”的报价详情中查看同一范围的完整记录与当时公开标记。保留原图片、设计、智能选品入口和单测试账号登录。
- 现行OpenAPI`pawday-v2.1.yaml`共336操作，TypeScript/Dart生成客户端同步。隐私结构盘点为153表/1229字段，保留/删除授权与生产证据仍为既有留白状态。
