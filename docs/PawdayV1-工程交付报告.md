# PawdayV1 工程交付报告

更新日期：2026-10-11。

已交付可运行的 PawdayV1 本机模拟工程版。M0–M5 和 M6.1–M6.6.3 已有对应工程报告；M6 生产总验收尚未关闭。每个历史阶段交付包及报告保留。

## 使用

桌面项目目录为 `PawdayV1`，双击桌面 **PawdayV1** 图标启动。先运行 Docker Desktop；Java 21 和 Node 随包提供。启动入口 `http://127.0.0.1:4172`，包含消费者 Flutter 工程预览、商家工作台、管理员工作台及 Android 调试 APK 下载。

消费者仅用合成测试身份；本机“查看测试账号”窗口提供随机密码、TOTP 和模拟短信。商品查找、宠物适配、购物车、试算、订单、支付、履约、售后、退款、账本、会员积分、内容评价、消息客服、附近预设与 AI 解释按已验收的开发环境边界验证。生产证据栏留白，真实业务与外部渠道不会因此开启。
