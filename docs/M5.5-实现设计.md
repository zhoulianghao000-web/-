# M5.5 DeepSeek 解释层实现设计

基线为 PR #17 合并后的 `d766a80cc257f0d7b36f1599a8a6804405fd401e`；实现分支 `codex/pawday-m5.5`，PR #18。本阶段工程验收与生产 DeepSeek 账号、计费、模型效果专项验收分别记录。

## 事实与模型边界

PostgreSQL 的已发布标准版本、有效商家报价、可售库存和 `pawday-fit-1` 是事实源。每次最多三个 SKU，自动候选排除确定性冲突并按预算过滤；手动选择的冲突商品仍展示“不建议”，关键资料缺失显示“信息不足”。不从 OpenSearch 或模型知识回填事实。

DeepSeek HTTP 接口返回 `evidence_ids` 选择计划。只允许本次发送的证据 ID、1–12 个且不重复，禁止自由正文、额外字段、截断响应及 tool calls。后端用核对过的商品卡片和模板生成解释，所有确定性结论和警告始终展示。模型不能创建订单、付款、退款、修改报价、修改权限或作医疗裁决。证据白名单收窄了 V1 的自然语言能力：当前支持既有商品资料整理、最多三个规格比较、明确“金额元以内”预算过滤，以及明确绝育状态的待确认建议；开放式医学问答、无证据知识补全和任意档案字段修改不在此交付能力内。

调用模型仅发送 SKU 证据 ID、证据种类、规则结论、配料/来源项数。不发送账户 ID、宠物 ID/姓名、电话、地址、备注、原始问题或历史聊天。商品名与价格由后端展示，不由模型生成。供应商密钥只在服务端配置。

适配器固定官方 HTTPS 主机、路径和禁止重定向；显式测试选项才允许 loopback HTTP。完整响应时限为 1–20 秒（默认 8 秒），正文最多 64 KiB。JSON 模式与关闭思考的请求参数按官方 API 文档实现：[DeepSeek Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion/)。默认模型是配置值 `deepseek-flash`，可以通过服务端环境配置替换。

## 额度和事务

用户行锁串行化额度判定。`ai_requests` 的 `(user_id,idempotency_key)` 唯一；请求指纹使用服务端 HMAC。请求创建与 RESERVED 账本同事务提交，随后释放事务再调用供应商。只有已验证结果、CONSUMED 流水、加密 assistant message 在同一事务持久化成功才扣次数。

普通额度按上海自然日统计；默认 3 次是可变运营基线。会员购买周期额度作为额外余额逐笔冻结：现有月度 20 次、年度 300 次按已付款订单快照与激活期限生成不可变 grant。续费 grant 从上一周期到期开始，不能提前借用。每日会员安全上限是另一个可配置约束，不改变购买周期总量。免费余额优先使用，界面同时显示普通与会员余额。正式生产运营应确认这些默认策略后发布版本。

HTTP 故障、输出拒绝、业务版本冲突及结果持久化失败释放 RESERVED；硬崩溃或数据库暂不可用则由 durable lease 扫描恢复。到期后的迟到结果不能消费额度。相同 key 不重复调用或扣减；失败释放后的再次请求必须使用新 key。客户端遇到网络结果不确定时保留同 key 查询/重试，服务端明确释放后才生成新 key。

结果落库前重新检查会话/用户状态、个性化偏好版本、会话有效性、租期、当前购买权益、宠物版本、标准版本、报价及库存版本。供应商故障不回滚商品或交易事实。

## 隐私和资料建议

个性化默认关闭，使用 current pet 需明确开启且服务端核验所有权。问题和已验证回答用现有 AES-GCM 机制加密，后台配置保留 1–90 天。主动清除或到期将会话关联宠物清空、消息密文清空、建议关联和差异值清空，并释放未完成请求。已确认宠物业务资料不会随清会话撤回。

当前资料建议只支持明确的绝育 YES/NO，保存前显示旧值→新值。`PENDING/ACCEPTED/REJECTED/EXPIRED` 独立持久化；接受时核对归属、建议时宠物版本和当前版本，必须是显式用户动作。模型回包不能直接修改档案。

## 管理、客户端和监控

`ai.read` 读取配置及验证记录，`ai.manage` 写入。所有写操作需管理员密码/TOTP 重新验证、一次性 proof、幂等键和同事务审计；发布还需 release 的 If-Match。提示、额度策略、评估和发布历史不可覆盖。灰度按稳定用户哈希；启用需白名单边界验证通过；回滚只能指向真实发布过的版本。`/admin/ai/rules` 只展示既有规则边界，未新增绕开商品/分类规则的 AI 规则修改接口。

边界验证记录检查 ID 白名单、重复、空结果及交易/诊断/自动改档案工具拒绝，明确不冒充云端模型质量评测。本阶段机器契约新增 22 个实际实现接口；M1 设计目录中的任意规则编辑/通用评测调度不自动计作已实现。

Flutter 首页入口、登录 returnTo、当前宠物/授权开关、会话历史/清除、异步返回隔离、错误/额度展示和资料差异确认已接通。管理员 Vue 提供策略/提示版本与评估、灰度、启用、回滚；商家 Vue 提供标准资料维护边界说明，不读取消费者会话。TypeScript/Dart DTO 由 `pawday-m5.5.yaml` 生成。

Micrometer 暴露 `pawday.ai.quota.requests{state=RESERVED|CONSUMED|RELEASED}` 与 `pawday.ai.quota.expired.leases`，无用户身份或问题标签。保留原有 Outbox/库存/退款/结算指标。

## 验证与生产边界

新增测试使用真实 PostgreSQL、真实 HTTP socket 故障供应商，覆盖并发额度/幂等、租期恢复、供应商协议/超时/大小限制、版本变化、撤回授权/注销、DB 回滚、清除/到期、购买周期/续费、RBAC/二次验证/审计和受控发布。CI 的三端联调使用实际浏览器、实际 Flutter Web/Dart Repository、四种真实基础设施及显式 TEST_ONLY HTTP 协议服务。

没有生产 DeepSeek 密钥，不宣称云端真实推理、模型效果或计费已验收。iOS 签名、实体手机、正式支付/物流/短信/云存储、备份恢复和容量准入仍按 M6 执行。M5 总验收评价工程闭环与上述边界，不等于生产上线许可。
