# Pawday V1 宠物档案与附近页优化验收报告

分支：codex/pawday-pet-nearby-refinement；受测代码：`6ae3349ce5d2816fd2f4e6e53a81a6f3e4f80ff3`。交付提交与文件 SHA256 见同名交付验证 JSON。

## 本轮修正

1. **品种**：按物种搜索平台词典；提供常见名称、自行填写和未知选项。主人填写单独保存，不伪造正式分类 ID，也不生成医学适配依据；更换物种会清空原品种。
2. **档案表单**：基本信息、年龄、过敏忌口分组，字段间距与窄屏排列调整。生日可选日期，也可粘贴 `2026 01 02`、斜杠或中文日期，严格校验后提交 ISO 日期；生日与估算年龄互斥，非法日期在提交前提示。年龄按完整日历月显示“岁/月”，估算加“约”，缺失显示待补充。
3. **宠物页**：限制内容宽度，桌面/平板/手机采用三/二/一列；空状态加入原参考本地照片、添加入口与档案/体重/当前宠物使用提示。
4. **照片卡片**：圆角矩形使用用户实际上传照片，深色渐变保证信息可读；照片失败回退品牌底色；操作区独立排列。复用受控上传、JPEG/PNG、5 MiB、哈希及实际文件校验；只有资源所属消费者可读取和绑定，活动宠物引用的照片不能删除。
5. **附近**：标题、城市/类别、快捷城市、查询/定位操作、提示、结果分区。模拟控制折叠到“测试场景工具”；定位拒绝后仍可按城市浏览。保留查询排序、分页、服务展示和导航边界。

V023 为 pets 增加两个可空引用/标签字段，不保存图片本体；保留旧档案、版本冲突、幂等、二次验证与审计。照片绑定与资源删除通过数据库锁避免并发悬空引用。隐私盘点同步到 145 表/1,155 字段；保留政策和删除授权没有被改成通过。

现行机器契约为 pawday-m6.6.3.yaml，生成 TypeScript/Dart DTO；历史契约继续独立校验。M5.2 实际响应校验使用现行 Pet schema，但仍保留原 M5.2 操作与二进制覆盖要求，未放宽额外字段拒绝或减少覆盖。
