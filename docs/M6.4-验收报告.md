## 本批结果

- 新增 V021：AI 清除、个性化撤权、AI 到期清理及媒体删除/废弃，通过数据库触发器与原业务状态、审计和幂等命令同事务提交。回滚不留登记或序号空洞。已有 V020 数据库真实升级并保守回填尚存终态；重复迁移不重复登记。V001–V020 原字节保留。
- 登记仅保存主体引用、动作、原因、时间和原到期依据，不保存正文、验证码或金额。串行计数器与导出屏障保证连续已提交前缀，避免后提交事务越过未提交记录。原有版本化 AI 保留配置继续适用，不新增法定保留周期。
- 独立 provider 边界、签名 checkpoint、不可覆盖文件、OS 锁、原子 latest、短事务 claim/lease、token fencing、持久化指数退避及覆盖心跳。IO 在事务外；存储失败或确认丢失不回滚业务或重复动作。旧 worker、签名正确但前缀冲突、覆盖时间倒退均拒绝覆盖/确认。
- 恢复读取备份之外的独立导出，以单独签名密钥、数据库/登记链来源、连续序号、必要截止时间及可信最新 checkpoint pin 校验。签名正确但陈旧/缺尾或篡改导出拒绝，恢复库不变。HMAC 不能单独证明完整；生产可信水位托管仍是前置条件。
- 真实物理恢复 gate 调用实际 AI 清除/撤权/到期与媒体删除服务，生成四条登记；先制造真实独立文件存储失败，再恢复导出。旧备份恢复后据此清除，重复回放事实一致，已删媒体不复活，搜索在真实停机后补偿重建和原子切 alias。账本/inbox/库存/支付/退款/结算/额度及待发短信隔离约束继续通过。
- 新增积压、覆盖年龄、失败和未覆盖四项固定维度指标及三项告警。Prometheus 真实受控抓取包含新指标，15 项规则通过 promtool 测试；17 项真实运维场景保留。新三项告警规则测试不冒充生产通知验收。
- 运行时 API 仍 303 项，无新增业务页面；三端保持原有流程并交付同一受测版本。
