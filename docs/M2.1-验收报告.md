# Pawday M2.1 验收报告

日期：2026-10-03。结果：M2.1 身份与授权基础实现、本机验证通过；M2 总体 Gate 尚未关闭。

源自 Pawday-M2-Bootstrap-0.1.zip。保持 Java 21 + Spring Boot 4.1.1，身份持久化改用 Spring JDBC；V001 未修改，新增 V002，database/migrations 与应用资源保持一致。

## 已实现

消费者 OTP 登录、设备会话、访问/刷新轮转、注销；商家密码登录、商户/门店授权交集；管理员密码 + TOTP MFA、实时 RBAC、角色创建/更新；二次验证绑定 session/action、300 秒有效、单次消费。角色写入具备乐观版本和幂等键；域与门店商户归属由组合外键约束。

审计包含主体/角色快照/会话/动作/对象/前后变更/请求关联 ID/掩码 IP；递归隐藏密码、令牌、验证码、手机号、地址。角色/审计/二次验证消费/幂等结果同事务提交。触发器拒绝审计 UPDATE、DELETE、TRUNCATE；审计故障不静默提交或绕过鉴权。

库内令牌仅存 SHA-256，OTP 为带密钥 HMAC，密码 BCrypt，TOTP 密钥 AES-GCM 加密。每请求重读权限和账户状态，禁用/降权立即生效。不允许客户端 merchant_id 覆盖身份；Basic/form/session-cookie 登录关闭，框架默认用户排除。

演示数据仅在显式 local、非 production、enabled 下初始化；密码/MFA 来源于本地生成的忽略文件，不覆盖已有凭据。正式短信未配置返回 503，没有万能验证码。

## 范围与下一阶段

本机无 Docker，Compose 整栈未执行；测试不是 Redis/RabbitMQ/OpenSearch 集成验收。正式短信/微信登录、员工开户、MFA 恢复待适配。员工角色/门店授权由受控初始化或数据库流程维护，本批未开放授予 API/UI。设备/角色/门店列表全量返回，审计为最近 limit 条视图，历史分页后续实现。

M2.2 Outbox、M2.3 存储搜索、M2.4 Vue/Flutter 实体工程待实施，本批没有声称支付/退款/结算已实现。客户端刷新须串行，管理员登录后 reverify 须等待新 TOTP 时间步；生产运行账号的 DDL 权限由部署流程独立管理。

下一步按计划进入 M2.2：业务事务与 outbox_event 同提交，再实现发布确认、重试/DLQ、幂等消费和受控重放测试。
