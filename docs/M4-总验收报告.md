## 核心不变量

- 金额一律整数分；Quote 固定版本化优惠应用顺序、同类叠加、最低实付与尾差算法，计算输入/输出快照随单冻结；部分退款不返券，整范围取消完成后退券一次，优惠守恒有测试门禁。
- 库存只经 Adjustment 命令与不可变流水改变；预占/转扣减/释放/返库逐件留痕，并发取消与发货由父单→子单→订单项锁与占用表唯一约束串行化。
- 支付与退款渠道 I/O 一律在业务事务外，意图先落库、渠道调用提交后执行；幂等键与渠道单号重放短路，渠道成功本地回滚由恢复 Worker 对齐，崩溃重启不重复扣款/退款。
- 取消请求即受理；可取消数量=付款−已取消−已发货，可售后数量=已发货−已占用，占用明细不可覆盖；运费仅整子单未发货取消退还。
- 账本 append-only，类型-方向由数据库 CHECK 绑定；佣金按支付时刻政策快照计算且不回溯，冲正按比例封顶；已结算退款经 SETTLEMENT_ADJUSTMENT 净额桥接，不重复计余额；对账端点 7 项不变量任一偏离即报差异。
- 写操作全部服务端幂等、RBAC 与审计同事务；政策管理、批次发起/重试、人工调整、平台裁决等高危动作强制二次验证；业务事实经 Outbox 同步，MQ 中断补偿重放不回滚事实。

## 准入边界与下一步
