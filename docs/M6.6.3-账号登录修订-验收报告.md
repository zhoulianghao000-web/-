# PawdayV1 账号登录修订验收报告

日期：2026-10-12。受测实现：`46d513668d36e4877a1ec704a80c5f61bd502eac`。交付版：1.0.1-engineering。

结论：代码清理与工程回归通过。管理员与商家均使用账号、密码登录；敏感操作仍须密码重新验证并立即消费与会话/动作绑定的一次性授权。

## 变更

- 删除管理员附加口令算法、匹配/重放计数、登录和再次验证参数、演示秘密配置及本机账号窗口中的对应显示。
- 删除 Web 登录页和各管理表单的附加输入框、状态、校验、请求参数；同步 OpenAPI、TypeScript client/DTO、Flutter DTO、CI 夹具、脚本与说明。
- 新增 V022 升级，移除旧认证存储列，恢复三身份主体形状约束。历史 V002 保持原校验和，以便已有数据库按 Flyway 正常升级；历史 SQL 和移除列的升级语句是唯一保留的迁移引用，不参与运行认证。
- 更新跨域隐私结构盘点为 145 表、1,153 字段。加密恢复验证使用仍存在的短信待发密文，保留密钥退休拒绝和恢复覆盖。
- 二次验证限流保持每分钟 10 次；长流程浏览器测试按实际请求计数等待下一限流窗口，没有放宽后端规则或重试业务写入。

消费者短信 OTP、Outbox 发送、密码加密、访问/刷新轮转、RBAC、商户/门店隔离、审计、幂等及其余业务流程保留。
