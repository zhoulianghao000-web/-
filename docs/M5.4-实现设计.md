# M5.4 附近与高德导航实现设计

基线：主分支 `50862fc39171b2abb23d645b0df160d6c9188394`，已包含 PR #16。保留 V001–V018，新增 V019；版本 0.5.4。

## 门店事实与发布

复用 `merchant_store` 与当前员工门店授权，不另建商家身份，不把商家身份当作认领或平台认证。`nearby_store_profile` 记录城市、四种地点类别、地址、电话、营业信息、GPS WGS84 坐标、可用服务和商家来源。

商家只能维护自己当前获授权的门店。创建以 `If-Match: "0"` 开始；每次修改递增版本，重置为 DRAFT / UNREVIEWED / 未认证，撤回公开结果。平台管理员核实认领依据、资质后可以公开、认证，或隐藏/拒绝；需 `nearby.read` + `nearby.moderate`、当前会话二次验证和原因。审核历史 append-only，禁止更新、删除。

所有命令通过已有 IdempotentCommandExecutor 在同一 PostgreSQL 事务中写事实、审计与 Outbox，版本冲突不会覆盖资料，失败不消费验证证明。`NearbyStoreChanged` 只携带 store_id/version，绑定 durable quorum business facts 队列。附近查询直接读 PostgreSQL 当前发布事实，不依赖 MQ 投影；事件重复投递不会改变查询结果。

本阶段只公开已存在商家门店的提交资料，不抓取/伪装高德 POI、导入外部医院资料或实现未认领外部 POI 的认领交易。医院只提供地址、服务说明、电话、来源；不作医疗诊断、疗效排名或预约可用性保证。

## 附近查询与隐私

公开 API 可游客访问。手动城市浏览按稳定门店 UUID 排序且 distance_m=null；主动定位后使用同一 WGS84 坐标系计算球面直线距离，默认 10 km，按实际距离/UUID 排序。允许类别筛选、限制范围/页大小，查询在数据库筛选排序后分页；offset 上限 10,000，数据变化时分页不承诺冻结快照。认证不参与疗效或距离排名。

位置只用于单次查询，不入业务表、Outbox 或审计内容。进入页面不调用定位。消费者主动点击后检查服务、权限，处理首次授权、拒绝、永久拒绝、服务关闭、超时与不可用；拒绝时仍能输入城市。位置只在当前页面内存保存，不请求后台位置权限/连续轨迹。坐标精度归一化为 6 位小数，错误坐标系拒绝，不静默转换。

## 高德交接边界

`NavigationProvider` 从当前仍公开的门店事实生成固定 HTTPS URI；客户端不能传 bucket、任意 URL、目的地坐标或用户起点。当前适配器是 AMAP_URI，可由服务端配置 `pawday.nearby.navigation-enabled=false` 关闭。

高德官方地点 URI 明确支持 `coordinate=wgs84`，因此交接固定为 `https://uri.amap.com/marker`，目的地 longitude,latitude/name 由服务端编码；callnative=1 尝试客户端，callnative=0 提供网页后备。高德页面负责选出行方式、规划路线和导航；Pawday 的 mode 只有 DESTINATION。未向坐标系语义不明确的 route 参数直接传 GPS。官方依据：[高德地点 URI](https://lbs.amap.com/api/uri-api/guide/mobile-web/point)。本适配器无需在三端嵌入生产 SDK 密钥。

消费者 NavigationLauncher 校验 scheme/host/path/参数/目的地一致性，拒绝 URL 注入；打开失败尝试网页，再失败显示地址手动搜索。打开 URI 成功只代表交接被系统接受，不声称已安装高德或实际开始导航。

## 验收门禁与范围

已有五个 CI Job 保留，新增真实 PostgreSQL HTTP/RBAC/幂等/并发/审核/回滚、RabbitMQ broker stop/start + publisher confirm、严格全覆盖 M5.4 HTTP 契约、实际 Flutter Web 浏览器授权/拒绝以及真实高德 HTTPS 响应。历史支付、退款、结算、私有客服和基础设施测试一并运行。

Flutter 平台接口单元测试验证不可用、超时、永久拒绝和 launch fallback；它们补充真实门禁，不替代 PostgreSQL/MQ/浏览器集成。Android Manifest 只有前台 coarse/fine 权限；iOS 只有 WhenInUse 说明。APK 构建、权限内容纳入交付校验。

M6 仍需实体手机的 Android/iOS 定位与已安装/未安装高德交接、真实门店资料及资质审核、生产网络和容量验收；未把 CI 浏览器当作实体手机。M5.5 DeepSeek 和 M5 总验收尚未启动。
