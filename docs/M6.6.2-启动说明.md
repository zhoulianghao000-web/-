# M6.6.2 重庆合成基线与资料标识启动说明

本批为工程准备，不是已完成的重庆现场试点。M6.6.2 已实现 cq-v1 合成基线和资料标识，M6.6.3 尚待统一联调及 20 人现场体验。正式生产 14 项门禁仍待补。

## 独立环境

需要 Java 21、Docker Compose、Node/pnpm；源码构建另需 Maven/Flutter。不要复用生产数据库、密钥、对象目录或旧本地环境。以下 PowerShell 在交付目录执行；Round 使用新的小写字母、数字和连字符名称。凭证仅生成在忽略目录 `.pilot/<Round>/config.env`，不要上传或粘贴到聊天。

```powershell
./scripts/pilot-environment.ps1 -Round cq-round1 -Action Init
./scripts/pilot-environment.ps1 -Round cq-round1 -Action Start
```

四服务独立 Compose project，PG/Redis/MQ/OpenSearch 分别绑定 loopback 5546/6386/5676/9206，管理端也仅 loopback。一次运行一个试点轮次；命名卷保留本轮状态，停止不是删除。根目录与数据库名必须属于专用轮次。当前启动器绑定 API `127.0.0.1:8086`，尚不开放现场 Wi-Fi 访问；现场网络和 TLS/设备接入在 M6.6.3 落实。

消费者使用合成标识 `+999000000001` 至 `+999000000020`，不可填真实手机号。它们是模拟系统身份，不是可接收短信的号码。OTP 经真实 Outbox/MQ 写入本轮 `sms/<challenge-id>.txt`，仅由现场操作员本地读取并交付指定参与者；不会发送手机短信，也不提供公开收件箱 API。启动时创建 20 个合成账户、各一个样例宠物和虚构地址，登录仍仅允许这 20 个标识。

商家测试账号为 `local-staff-a` / `local-staff-b`，管理员为 `local-admin`，密码及 密码验证 enrollment 原始随机材料保存在本轮私有配置中。管理员继续验证 密码验证，一次性 reverify 继续有效；操作员用本地配置将 密码验证 Base64 原始字节按 Base32 导入验证器，不能直接将 Base64 字符串作为 Base32。尚无面向人员的账号发放 UI，后续批次补体验与任务说明。

## 三端与模拟边界

商家/管理员交付 dist 使用 `VITE_PAWDAY_PILOT=true` 构建；运行时也需设置此变量，让开发或预览代理转到试点 API 8086。使用同源 `/api/v1`，不要求跨域放行。另开两个 PowerShell，在交付目录分别执行：

```powershell
pnpm install --frozen-lockfile
$env:VITE_PAWDAY_PILOT='true'
pnpm exec vite preview --config merchant-web/vite.config.ts --outDir ../release/merchant-web
# 浏览器访问 http://127.0.0.1:4173
```

```powershell
$env:VITE_PAWDAY_PILOT='true'
pnpm exec vite preview --config admin-web/vite.config.ts --outDir ../release/admin-web
# 浏览器访问 http://127.0.0.1:4174
```

源码开发使用 `pnpm dev:merchant` / `pnpm dev:admin`，同样设置 `VITE_PAWDAY_PILOT=true`；不要遗留 `VITE_API_BASE_URL` 指向其他环境。消费者交付 APK 使用 `PAWDAY_PILOT=true`、loopback API 8086；USB 调试设备可由操作员使用 `adb reverse tcp:8086 tcp:8086` 连接本机。正式现场无线版尚未交付。

试点客户端与服务端通过固定环境标识核对。普通客户端拒绝访问试点 API，试点客户端拒绝普通服务端响应；该标识不替代账号认证。公共浏览接口在试点也要求受邀会话，三端有持续模拟提示。附近仅固定重庆坐标，允许/拒绝/服务关闭选择不调用设备；目的地只预览，附近页面可选择“模拟导航失败”，仅展示预设提示，不调用导航 provider。

本地支付、退款与结算仅更新模拟事实；SMS 写本轮目录；AI 用本地证据选择器，无 HTTP 客户端，不能当成 DeepSeek 效果验收。真实 AI key、外部基础设施地址、普通数据库名、媒体/SMS 目录越界、启用导航或隐私导出等配置会拒绝启动。生产与恢复隔离拒绝门禁不变。

## 暂停与停止

```powershell
./scripts/pilot-environment.ps1 -Round cq-round1 -Action Pause
./scripts/pilot-environment.ps1 -Round cq-round1 -Action Resume
./scripts/pilot-environment.ps1 -Round cq-round1 -Action Stop
```

Pause 在本轮根目录写 `PAUSED`，API 包括已有会话立即返回暂停；不会撤销 token 或删除账本。它不停止本地模拟 worker；如需完整停机，先 Ctrl+C 停应用再 Stop 四服务。Resume 由负责人确认问题已解决后执行。用户主动退出/会话撤销继续走既有认证契约。每轮重新建立基线只针对专用环境，当前不提供清库或账号注销脚本。

## 本批基线及任务

启动器自动初始化 `cq-v1`：2 商家 / 2 门店 / 20 身份 / 20 SKU。首次基线完成前 API 暂不可用；成功重启不重置数据。相同版本定义变化会拒绝启动，不能覆盖旧轮；新轮使用新的 Round，停止旧轮后再启动。未提供“删旧轮”脚本，停止不会删除账本、卷或图片。

SKU 标识 `PILOT-CQ-V1-01` 至 `20`；01–16 是已知合成资料、17–20 是未核验合成场景，显示信息不足。身份 01 与 11 的样例猫可对 SKU 01 验证正向/过敏冲突，两者都不是现实适配建议。切换宠物后刷新结论。商品图片是本库生成色块，非商家授权照片，仅邀请登录后可读取。

消费者商品详情/对比、商家和管理员标准详情可见资料标签。管理员审核界面原有新资料验证要求仍保留；本批内部 SQL 种子不会扩大实际商品发布权限。未收到任何可追溯商家资料，不在本批声称已经授权。
