# Pawday M5.1 复核修正版启动说明

交付版本：0.5.1-review1。后端项目版本：0.5.1-SNAPSHOT；Android 应用版本：0.5.1，build 2。包含 M4.5 售后/退款、M4.6 结算、M5.1 会员/积分及本次复核修正。M5.2 尚未实现。

## 后端与四服务

需要 Java 21、Docker Desktop（Linux containers）与 Docker Compose。解压 Development ZIP 到独立目录，保持 `release/pawday-backend.jar`、`scripts`、`compose.yaml` 的相对位置。在解压根目录打开 PowerShell：

```powershell
./scripts/init-local.ps1
./scripts/start-local.ps1
```

第一个脚本仅在首次启动时执行，生成 `.env.local` 和 `.local-authenticator.txt`。第二个脚本等待 PostgreSQL、Redis、RabbitMQ、OpenSearch 健康后运行包内 JAR；开发包无需 Maven。源码包构建需 Maven 3.9+：`mvn -B -ntp -f backend/pom.xml -DskipTests package`。

后端监听 `http://127.0.0.1:8080`，聚合健康检查为 `/actuator/health`；Compose 端口分别是 5432、6379、5672/15672、9200/9600。已有服务占用端口时，须一致调整 Compose 映射及 `.env.local` 中对应服务地址。Flyway 自动执行到 V016，已发布的 V013–V015 保持原校验和。已有本地数据库应保留原密钥配置，不能重新生成密钥后继续使用旧密文。

商家演示账号 `local-staff-a` / `local-staff-b`，管理员 `local-admin`；随机密码在 `.env.local`。按 `.local-authenticator.txt` 中 Base32 密钥配置身份验证器。管理员登录与敏感操作需要 TOTP；同一时间窗的验证码只可用一次，二次验证须等待新验证码。开发短信由真实 Outbox/RabbitMQ 异步写入 `.local-sms`，消费者手机号登录使用该测试验证码。

## 商家与管理端

需要 Node 24、pnpm 11.25.0。在解压根目录：

```powershell
pnpm install --frozen-lockfile
pnpm dev:merchant
```

另一个终端执行 `pnpm dev:admin`。商家端 `http://127.0.0.1:5173`，管理员端 `http://127.0.0.1:5174`，开发代理转发到 8080。包内 `release/merchant-web`、`release/admin-web` 是经 CI 验证的静态构建；部署这些目录时需配置 `/api` 反向代理到后端。退款页对有 `payment.requery` 权限的管理员提供失败退款恢复入口，经密码/TOTP 二次验证后按原退款号核查渠道事实并恢复处理。

## Android 消费者端

另附 debug APK 来自同一修正提交的 Flutter CI，应用版本已核验为 0.5.1+2。该 APK 默认 API 地址为 `http://127.0.0.1:8080/api/v1`。连接开发电脑的 Android 设备/模拟器后，可使用 Android platform-tools：

```powershell
adb install -r Pawday-M5.1-Review-Consumer-0.5.1-review1-debug.apk
adb reverse tcp:8080 tcp:8080
```

设备连接与后端必须保持运行。需要直接使用 Android 模拟器宿主地址时，从源码重建：

```powershell
cd consumer-app/flutter
flutter pub get --enforce-lockfile
flutter run --dart-define=PAWDAY_API_BASE=http://10.0.2.2:8080/api/v1
```

实体机无线连接须使用可达的开发地址并相应配置后端监听；生产 release 使用实际 HTTPS 服务地址。Flutter Web 的示例 HTTPS 域名用于构建验证，不能当成已部署的生产服务。iOS 签名/设备验收仍在后续范围。

## 验证与停止

完整基础设施故障门禁执行 `./scripts/test-infrastructure.ps1`，使用隔离的真实四服务，不以 mock 代替。前端门禁命令及真实联调环境见 `docs/M2.4-前端工程说明.md` 和 `.github/workflows/frontend.yml`。

停止后端使用该终端 Ctrl+C；四服务使用 `docker compose stop`。本交付保留数据库/媒体/密钥文件，不需要删除卷。当前支付、退款和结算为开发模拟渠道；生产接入及恢复演练按 M6 执行。
