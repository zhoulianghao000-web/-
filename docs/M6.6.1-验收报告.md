## 已实现

- 合并重庆集中现场 Android 模拟试点范围：2 商家、2 门店、20 名受邀用户、20–50 SKU 为规划基线，未将规划数量写成已完成的现场数据或人员。自营/入驻混合经营意愿、未核验资料例外、合成适配、暂停规则及独立轮次已记录。原待确认文件转为现行计划入口，访谈保留历史依据。
- 服务端只允许 20 个固定合成消费者标识及两个商家、一个管理员测试登录名。非受邀 OTP 在创建账户/挑战/Outbox 前拒绝；既有非受邀会话及 refresh 也拒绝。受邀不能绕过 RBAC、merchant/store scope、TOTP MFA、reverify 和审计。
- 公共浏览在试点也要求受邀登录；API 校验客户端试点标识并返回环境标识及 no-store。三端持续显示模拟提示；客户端拒绝普通服务端响应。标识用于环境核对，不能代替认证。试点公开商品读取支持会话刷新，匿名认证请求不携带过期 bearer。
- 专用 `local,pilot` 配置、loopback 四服务、`pawday_pilot_*` 数据库、独立命名卷及轮次媒体/SMS 目录。误用普通数据库、外部基础设施、目录越界、真实 AI 凭证、外部 provider 开关、隐私导出或导航启用均拒绝启动。生产/恢复拒绝锁保持有效；没有真实供应商适配器或对公网开放操作。
- 支付/退款/结算沿用本地模拟器；OTP 仍经 PostgreSQL 同事务 Outbox、真实 RabbitMQ 到本地文件，未改回同步发送。AI 选择已有证据 ID 的本地模拟器不发 HTTP，不当作 DeepSeek 效果。物流沿用既有人工模拟事实，不接真实发货接口。
- Flutter 预设重庆坐标及允许/拒绝/定位服务关闭分支，不调用真实设备定位；目的地仅本地预览，导航 launcher 在试点拒绝外部 URI。导航失败的完整场景展示留待下一批。
- `pilot-environment.ps1` 初始化私有随机凭证、启动独立 Compose、暂停/恢复及停止。暂停使已有会话和 API 请求立即返回 503；不删除账本或撤销凭证，也不终止本地 worker。彻底停机需停止应用及该 Compose project。停止保留本轮卷，未提供清库/注销脚本。
- 商家/管理员开发和 Vite 预览代理均按试点标志路由至 8086。交付 dist 和 debug APK 均为试点构建；APK 指向 loopback，通过 USB adb reverse 做工程预览。本批尚不支持 20 人现场 Wi-Fi 接入。
