# M6.6.2 重庆基线与资料标识

基线来自包含 PR #24 的主分支 `e06221709cbb03fad5a4ee75477dc869693bb36f`。本批仅为模拟试点工程，非现场结果或真实交易准入。实际商家授权材料尚未收到；本批所有商品、图片、配料、过敏原、宠物、地址和门店均为生成测试资料。没有把口头同意登记成可追溯授权。

## 本轮数据

基线版本 `cq-v1`；固定 2 个合成商家、2 个重庆合成门店、20 个合成消费者、各 1 个样例宠物和虚构地址、20 SKU、20 个报价及对应初始库存明细。前 16 SKU 为合成已知资料，后 4 SKU 模拟未核验场景，配料/营养保留空数组、过敏原未知。门店认领状态仅为合成审核结果，名称和界面明确“非实际核验”，非平台认证，不可到店、付款或发货。

输入清单在 `backend/src/main/resources/pilot/cq-v1.json`，事实初始化在同目录 SQL。定义 SHA256 绑定 JSON 和 SQL；实际 PNG 另有媒体 SHA256。确定性 ID 仅用于本轮固定样例，不能作为授权凭据。

`local,pilot` + `pawday.demo.enabled=true` 的专用环境才运行初始化。M6.6.1 启动拒绝规则继续约束数据库、目录和外部调用。普通模式不会运行 initializer；保留前缀 `pawday-pilot` 的来源不允许经普通商品写入/读取接口自动转为正式商品。

## 原子性与重启

商家账号先初始化，再执行基线。服务启动后的 API 在基线完成前返回 503；只在业务事务提交后开启试点请求。所有测试业务记录、初始库存 Adjustment、基线摘要、审计及 20 个 CatalogStandardPublished Outbox 事件在同一 PostgreSQL transaction 提交，advisory lock 串行化竞争初始化。RabbitMQ/搜索不参与该事务。

二进制通过既有 ObjectStorageProvider 写本轮目录；PostgreSQL 仅保存媒体引用和元数据。不可覆盖的对象写入在事实事务前，回滚至多留下无引用的合成占位对象。同 Key 已存在时核对 hash/大小，不覆盖。中途失败重启可补齐；基线摘要存在但定义变更拒绝启动，不能原地修改同版本重置业务。成功后的普通重启不补库存、不覆盖宠物或订单、不重放初始事件。新轮次使用新的专用环境，Stop 保留本轮卷；本批不提供清库命令。

沿用既有 21 份迁移和 145 表/1155 列，无新增数据库字段；来源快照由已有不可变 source_refs 表达，基线摘要用 operation_config，不将二进制或反馈正文塞入业务数据库。

## 资料与适配

`pilot_material` 只在试点返回。SYNTHETIC 需匹配固定 SKU、固定不可变标准版本及来源标识；复制文本到新版本不会得到该资格。其他试点资料保守标记 UNVERIFIED；所有结果 `production_approved=false`。未知资料先消除依赖未核验商品的冲突结论，返回 INSUFFICIENT_DATA / 信息不足及 PILOT_MATERIAL_UNVERIFIED，避免以分类、年龄或过敏原假设给出可靠结论。

样例 01 用户/猫无合成过敏，SKU 01 可验证 SUITABLE；样例 11 用户/猫有合成过敏，同 SKU 可验证 NOT_RECOMMENDED。SKU 17–20 验证信息不足。合成年龄规则覆盖所有非负月龄，仅用于控制流测试，绝非兽医年龄阈值。

三端标准资料显示来源标签。消费者列表、详情、对比与适配展示同一版本；未知配料显示信息不足。图片仅为本库生成色块，界面说明非授权商家图片。

## 受邀媒体

新增 consumer/pilot/baseline 与 consumer/pilot/skus/{sku_id}/media 两个 GET。仅受邀消费者会话可读；媒体路径由服务端生成，不接受任意对象 Key 或 asset_id。读取验证当前有效标准的固定引用、READY / PRODUCT / local、归属门店、活跃商家及所有者，核对对象 hash/大小。退役标准不再提供图片。已发布标准的媒体引用阻止删除，沿用 owner/scope 与媒体恢复规则。

Flutter 用 API 客户端携带 Bearer + 环境标识读取二进制，验证响应环境、限制 5 MiB、允许 GET 刷新；退出/切换会话丢弃迟到数据，图片仅保存在组件内存，非公开 URL、非跨账号磁盘缓存。三端既有权限、MFA、reverify 与审计不变。
