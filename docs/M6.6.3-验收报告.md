## 修正与交付来源

断网浏览器发现远程中文字体 fallback 导致方框字，已内置字体并重建；精简 Java 初版缺少 `jdk.net`，已补齐模块并实际启动；目录隔离修正后独立卷和重启均通过。6ac 候选的真实前端 CI 在 Flutter AI 页面异步重建时焦点断言失败：偏好与额度加载会插入输入框前的组件，已给问题编辑器稳定 Key，保留节点及焦点；测试同步重新获取编辑器并等待渲染，实际输入、焦点及后端载荷断言仍保留。851097d 候选又暴露商家附近资料的异步覆盖：资料尚未返回时允许输入，响应覆盖了城市字段，保存被原生必填校验阻止。现已在加载/保存期间禁用整组编辑，加载失败保持禁用，成功读取或明确 404 新建后才启用，并增加延迟/失败/重试回归。早期候选失败和重复 CI 保留诊断，最终报告只计入上述最终受测实现，不把失败记为通过。
