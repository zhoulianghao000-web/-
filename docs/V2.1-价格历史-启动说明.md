# V2.1 价格历史启动说明

本批升级沿用桌面 `PawdayV1` 目录和快捷方式，内部版本为2.0.1-engineering；消费者Web/Android为2.0.1+21。现有单消费者测试账号、商家与管理员账号保留。本地模拟环境，生产留白安排不变。

## 使用

- 消费者Web/Android：登录或安卓游客浏览后，打开“分类”，选一个商品，在商家报价下点击“查看价格记录”。可切换30/90天、查看普通/会员标价和逐日记录。失败时使用“重试”。
- 商家/管理员：打开“报价与库存”，点击“查看报价与流水”。下方价格记录支持30/90天、曲线和逐日表。商家仅查看已授权的商户/门店报价；管理员需报价读取权限。
- 价格以整数分存储，界面显示人民币元；曲线是同一Offer每日最后已记录的商品报价。运费、券、结账实付、成交价和库存不包含在历史报价内。

## 数据说明

升级V026时仅采集当前报价基线，不补造旧日期。刚升级时可能只有当天一个价格点，过去日期显示“未采集/未公开”，这是正常状态。此后报价或销售状态改变会在同一PostgreSQL事务中追加记录；历史不能由业务接口编辑或删除。

消费者仅看到记录时已公开且当前仍可公开的报价。商品后来再发布，不反向放开旧的私有改价。缺口不连线。管理端可以看自身授权范围的完整记录，包括当时未公开的报价及状态。

## 安装及启动

双击原桌面快捷方式，或目录中的“启动PawdayV1.cmd”。消费者网页 http://127.0.0.1:4175 ，商家 http://127.0.0.1:4273 ，管理员 http://127.0.0.1:4174 。账号密码在本机“查看测试账号”私有窗口查看，不需要模拟短信验证码。

Android安装 `Pawday-Consumer-2.0.1-price-history-debug.apk`，使用上一批相同的固定内部测试签名；已安装上一批固定签名版时可覆盖升级。如果手机仍为更早的临时签名版，签名冲突时需先卸载旧测试版再安装。不要卸载电脑开发目录或删除`.pilot`。USB连接时保持桌面服务运行，并使用“Pawday安卓连接”配置8086端口转发。
