# PawdayV1 宠物档案与附近页优化版启动说明

版本：1.0.4-engineering；消费者 0.6.10+16。本机模拟环境，需要 Docker Desktop 运行。

1. 双击原桌面「PawdayV1」图标；或完整解压开发 ZIP 后双击「启动PawdayV1.cmd」。不要只解压 APK 或 release 文件夹。
2. 入口：http://127.0.0.1:4172；消费者：http://127.0.0.1:4175；商家：http://127.0.0.1:4273；管理员：http://127.0.0.1:4174。已打开页面按 Ctrl+F5。
3. 管理员 local-admin，商家 local-staff-a / local-staff-b。双击「查看测试账号.cmd」查看本机原密码；本次未重置密码。
4. 消费者使用指定测试手机号 +999000000001 至 +999000000020，申请验证码后切换至上述账号窗口，点击底部 Refresh local SMS codes，找到同一手机号最新一行的六位数字，回消费者页填写后登录。短信只写入本机。
5. 登录后点击「宠物」→「添加宠物」：选择物种，再搜索品种或自行填写；照片支持 JPEG/PNG、最大5 MiB；年龄方式选择已知生日/估算年龄/暂不填写。生日可直接输入2026 01 02，保存时转换为标准日期。
6. 「附近」可以直接输入城市查询；模拟定位和导航异常在页面下方折叠的「测试场景工具」内。模拟模式不会调用真实设备定位或外部导航。
7. Android 安装本次新的0.6.10 debug APK；USB 连接电脑后执行 adb reverse tcp:8086 tcp:8086，保持电脑本机服务运行。APK API 地址 http://127.0.0.1:8086/api/v1。Web 则通过4175同源 /api/v1 代理访问。
8. 「停止PawdayV1.cmd」只停止本项目服务，保留数据库、照片和账号。敏感操作仍需要再次输入密码。

原11张参考图片、字体和动画保留并本地加载。开发命令与 CI 见仓库 package.json、.github/workflows/ci.yml 和 frontend.yml；现行机器契约 openapi/pawday-m6.6.3.yaml。开发包不包含私有测试凭据；首次在新目录启动会初始化独立本机环境。

14 项生产资料继续留白，M6 生产总验收未关闭。本包用于内部模拟工程测试。
