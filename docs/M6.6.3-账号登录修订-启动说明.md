# PawdayV1 1.0.1-engineering 账号登录修订启动说明

本批在 M6.6.3 基础上交付账号登录修订。管理员与商家都只需账号和密码；敏感操作再次输入密码。人员现场体验已由用户取消；14 项生产资料填写栏留白，生产准入未通过。此版本仅用于本机模拟验证。

## 桌面启动

1. 运行 Docker Desktop，等待引擎就绪。开发交付包已附 Windows x64 Java 21 运行时和 Node 运行时，无需另外安装 Java、Maven、Node、pnpm 或 Flutter 即可启动。
2. 双击桌面 **PawdayV1** 快捷方式，或解压项目中的 `启动PawdayV1.cmd`。首次启动会初始化独立轮次，并启动 PostgreSQL、Redis、RabbitMQ、OpenSearch 和应用；不复用其他项目的容器或数据库。
3. 浏览器打开 `http://127.0.0.1:4172`，选择消费者工程预览、商家工作台或管理员工作台。消费者浏览器预览是 Flutter 工程验证入口，不是公开 Web 商城。
4. 双击 `查看测试账号.cmd`，在本机窗口查看本轮随机账号密码。申请消费者验证码后刷新该窗口，读取模拟短信。该窗口仅访问本轮私有文件，HTTP 服务不提供密码、验证码或配置文件下载。

入口：4172；商家：4273；管理员：4174；消费者预览：4175；API：8086。全部绑定 `127.0.0.1`，不向其他设备开放。四服务端口为 5546 / 6386 / 5676 / 9206，RabbitMQ 管理端为 15676，均仅本机访问。端口被其他项目占用时启动器拒绝启动，不结束其他项目。

消费者仅允许 `+999000000001` 至 `+999000000020` 合成身份。商家 `local-staff-a` / `local-staff-b`，管理员 `local-admin`；密码每个独立环境随机生成。敏感操作须再次输入密码。启动器按解压目录生成唯一轮次 `desktop-<12位目录标识>`，私有配置在 `.pilot/该轮次/config.env`，不上传、不放进交付包、不粘贴到聊天。不同目录各有独立 Compose project 和卷，不共享测试密码或库存。

## Android

交付包 `release/consumer.apk` 为 0.6.8+14 试点调试 APK，本批为模拟主题内置 Noto Sans SC 中文字体及完整 OFL 授权，消费者工程预览不再依赖外网字体下载。可在入口页下载。连接 Android USB 调试设备，执行 `adb reverse tcp:8086 tcp:8086`，安装 APK 后访问本机 API。ADB、设备授权和正式签名不包含在一键桌面启动中。

## 停止与重启

双击 `停止PawdayV1.cmd`。只停止本目录登记且启动时间匹配的应用进程，以及专用 `pawday-pilot-desktop-<目录标识>` 容器；保留本轮卷、媒体、账本和随机账号。关闭网页不会停止后台服务。再次点击桌面图标会重用健康的本机服务，不重复初始化库存和账本。

如需暂停业务请求，在 PowerShell 先通过 `Get-ChildItem .pilot -Directory -Filter 'desktop-*'` 查看本轮名称，再执行 `./scripts/pilot-environment.ps1 -Round <本轮名称> -Action Pause`；恢复用 `Resume`。这不撤销已有会话，也不等同于停掉 worker。

故障日志在 `.pilot/本轮名称/backend.log`、`backend-error.log`、`desktop.log`、`desktop-error.log`。如端口占用，先停止拥有该端口的环境；如 Docker 未运行，先启动 Docker Desktop。不得通过修改配置绕过模拟或生产拒绝门禁。
