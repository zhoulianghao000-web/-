# M6.4 在线隐私登记与保留事实链

本阶段从 PR #21 合并主分支 `333c2f636b2df0296940686e05cc2b6a92b8be85` 推进。范围是既有 AI 清除、个性化撤权、AI 到期清理和媒体删除/废弃的事务登记、独立导出、覆盖水位及恢复拒绝门禁。正式隐私政策、账号注销、法定保留期与生产恢复仍未验收；14 项生产条件保持 PENDING。

## 事务事实

V021 新增 `privacy_journal_head`、不可修改/删除/清空的 `privacy_journal` 和可恢复的 `privacy_export_state`。V001–V020 保持原字节。数据库 AFTER UPDATE 触发器在原业务事务中登记，不依赖调用方记得发送消息。审计或幂等命令提交失败会同时回滚业务状态、登记和计数器。

| 既有动作 | 登记种类 | 保留依据 |
| --- | --- | --- |
| AI ACTIVE → DELETED | AI_CONVERSATION_DELETE | USER_DELETED |
| AI ACTIVE → EXPIRED | AI_CONVERSATION_DELETE | RETENTION_EXPIRED；记录原 expires_at |
| 个性化 true → false | AI_PERSONALIZATION_REVOKE | CONSENT_REVOKED；重新授权后再撤回仍追加新事实 |
| 媒体进入 DELETE_PENDING/DELETED/FAILED/EXPIRED | MEDIA_DELETE | USER_DELETED / UPLOAD_DISCARDED |

登记不保存问题、回答、验证码、对象正文或金额。AI 到期时间来自原有版本化配置形成的会话事实，不新增法定保留周期；备份/WAL/对象版本/历史密钥仍受恢复链 pin 保护，清理计划仅供审查，不自动删除。迁移保守回填尚存的终态记录和关闭状态，不声称补全已经消失的迁移前历史。

计数器行锁一直持有到业务提交；回滚不留空洞。导出在 READ COMMITTED 事务内先 claim，再锁计数器，读取已提交的完整连续前缀，并使用 PostgreSQL 时钟给出 covered_until。后来的登记等待快照结束，防止已覆盖水位跨过未提交事实。全局串行锁的吞吐成本需要后续容量实测。

## 独立导出

`PrivacyExportProvider` 是持久化边界；`PrivacyExportService` 在提交短 claim/快照事务之后才调用 provider。数据库记录 claim/lease、已确认序号、覆盖时间、checkpoint SHA256、错误码、退避和尝试次数。失败保留登记，指数退避最多一小时并持续重试；不会因超限永久丢弃隐私事实。worker 崩溃后 lease 到期接管，迟到确认受 token 限制。

开发适配器使用独立目录、OS 文件锁、不可覆盖 checkpoint、HMAC-SHA256、文件强制落盘和原子 latest 替换。相同前缀可重试，旧 worker 不可覆盖较新水位；来源、签名、前缀冲突拒绝覆盖。Linux 强制同步目录；Windows 不承诺断电持久性。根目录必须由服务账号独占，签名密钥与登录/数据加密密钥分离；不能与媒体目录重合。生产独立故障域、WORM、KMS、密钥轮换和最新水位托管尚待正式供应商实施。

当前导出上限为 10,000 条 / 1 MiB 完整前缀，超限拒绝导出并要求容量方案审查，不能截断后声称完整。默认 exporter 关闭；未配置独立根目录与单独签名密钥时不可开启。登记始终生效；指标暴露未覆盖/落后状态。此限制与配置状态均不构成生产验收通过。

## 恢复拒绝门禁

`scripts/privacy_export_contract.py` 校验签名、严格字段、连续序号、来源数据库/登记链、覆盖时间，以及来自恢复备份之外的最新 checkpoint pin 和最小序号。只有正确 HMAC 的旧文件或空文件不能证明最新完整。最新 pin/最低序号/必要截止时间须由隔离审查的可信独立来源提供，不能采用恢复出来的 `privacy_export_state`，也不能让待验证文件自行证明自己是最新。

真实 PITR 门禁已改用实际 AI 清除/撤权/到期 worker 和媒体删除服务生成四条登记，再调用真实导出器：先制造独立存储失败，证明业务已提交，再补齐并导出。恢复旧备份后，旧认证导出、篡改导出先拒绝且数据库不变；使用独立最新 pin 验证后才允许离线白名单清除与搜索重建。导出中的到期清理以删除 tombstone 回放，保守防止旧正文复活。

恢复应用、外部 MQ/SMS/支付/结算 worker 仍全部隔离。离线回放会在恢复库形成局部登记，这些不是新的生产授权事实：恢复登记链、独立来源和待发送事件尚需后续受控核对，绝不能直接启动 exporter 或解禁业务。工具不返回生产提升/上线授权。

## 指标与门禁

固定维度指标：`pawday_privacy_export_backlog`、`pawday_privacy_export_coverage_age_seconds`、`pawday_privacy_export_failures`、`pawday_privacy_export_unavailable`；无用户或对象标签。新增失败、积压、覆盖过期三类告警和真实 promtool 规则测试。

验证包含 PostgreSQL 回滚/连续提交/快照屏障、实际 HTTP 清除和审计回滚、媒体审计回滚、真实独立文件导出故障/重试/确认丢失/lease/fencing、旧认证和缺尾拒绝、真实 WAL/PITR 与 OpenSearch 故障补偿。最终统计及构建来源以本阶段验收报告和交付验证 JSON 为准。
