## 本批范围

1. 消费者首页原猫咪提示条改为“智能选品”，保留图片和副标题，固定在右下角、底部导航上方。滚动不改变入口位置，点击进入现有 AI 页面；游客需登录后返回选品页。
2. 商家、管理员工作台及桌面门户提供相同固定入口，打开消费者选品页，不传递员工身份令牌。原有管理员 AI 管理功能保留。
3. Android 模拟版登录页去除重复且无响应的关闭按钮，标题、跳过与表单上移，键盘打开后跳过仍可触达。
4. 当前消费者模拟网页与 Android 改用用户指定的单一账号密码，不再获取或刷新登录短信。账号标识不用于短信发送，映射既有首个模拟消费者，保留数据。
5. 单账号模式阻止其他模拟消费者会话与旧 OTP 登录；保留会话刷新、限流、暂停、禁用账号及三身份权限边界。普通部署默认禁用该测试接口，开启必须依赖明确模拟环境。
6. Windows 测试账号密码以当前用户 DPAPI 私有配置保存，不纳入源码、开发包、CI 或报告。测试账号窗口移除验证码刷新区。商家与管理员配置保持原样。

## 安装及边界

后端JAR、商家/管理员/门户静态文件、消费者Web及APK均取自最终CI产物。桌面保留原私有配置、数据库与快捷方式，不重建测试数据。

APK采用固定内部测试签名；与旧临时签名不同，旧版覆盖安装可能失败，需要一次卸载重装。此后交付链沿用该内部签名；生产签名留白。原图资产逐项按SHA256核对。

本次未自动卸载手机应用，也未将新 APK 已在实体手机运行作为验收结论；Android 依据 Widget 测试、CI 构建、包元数据与签名核验。USB连接仍通过本地8086端口转发。

本批仅为已授权的本地模拟体验维护。14项生产证据、运营通知仍留白；不宣称V1全部需求或M6生产总验收关闭，不启动V2/V3。
