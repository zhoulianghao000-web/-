# M6.5 启动与复核说明

开发包为 0.6.5，Flutter 0.6.5+11 debug APK。开发启动沿用 `scripts/init-local.ps1`、`scripts/start-local.ps1`；开发包 JAR 位于 release/pawday-backend.jar。正式环境仍被生产准入与恢复隔离拒绝器阻断。

## 数据结构复核

```powershell
mvn -B -ntp -f backend/pom.xml -Dtest=PrivacyInventoryTests test
python scripts/check-privacy-inventory.py --schema-json backend/target/privacy-review-schema.json --report backend/target/readiness-evidence/privacy-inventory.json
python -m unittest discover -s scripts/tests -v
```

第一条命令使用真实隔离 Embedded PostgreSQL，不连接业务实例。第二条只读取结构元数据文件和冻结清单，输出报告；PASS 仅代表结构覆盖。缺文件、新增迁移或未复核结构都会返回非零。工具没有注销账号、修改保留期限或解除恢复隔离参数。

## 真实物理恢复门禁

Linux CI recovery-engineering Job 构建实际 JAR/helper，运行 compose.recovery.yaml 隔离 PostgreSQL/OpenSearch，执行 scripts/recovery-engineering-gate.py --test-only --commit 指定提交。输出 recovery-gate.json、privacy-schema-review.json、privacy-rejoin-review.json。恢复接入报告预期为 BLOCKED；真实登记分叉、待发 Outbox 以及全表事实未改变才算工程测试通过。

该命令只接受固定合成容器，要求内部网络、标签和无公开端口；不支持传入生产主机。备份、WAL、媒体副本及主体登记不进入开发包。开发目录 .local-recovery 已存在时拒绝覆盖，请保留既有私有证据后另行建立隔离演练。真实账号注销、供应商和生产恢复尚待后续验收。
