# Pawday V1 筛选排序与求购测试说明

本机工程模拟版，消费者0.6.12+18，交付1.0.6-engineering。双击桌面PawdayV1，等待本机服务健康；原测试账号/密码保留，在本机测试账号窗口查看。网页Ctrl+F5更新构建。运营通知按用户要求留白，14项生产资料继续PENDING。

1. 消费者进入“分类”或“商品与适配”，填写商品名/品牌/规格代码；展开“筛选与排序”。可组合宠物类别、品牌、年龄、粮食类型、价格、包装规格/单位、库存与排除过敏原，选择综合/价格升降/销量/好评，点击“查询 / 刷新”。价格填元（最多2位小数），包装填克。清空筛选恢复全部。
2. 价格按满足库存条件的最低有效商品报价筛选，不含运费和优惠；排除过敏原时，信息未知的商品不保留。不自动放宽条件。翻页中结果变化会提示重新查询。
3. 没有结果时可放宽条件，或“我想买这个商品”，填写合成测试名称/需求。会保存搜索条件；不要填写真实手机号/地址。求购不是订单，不扣款，不承诺采购或到货。
4. 消费者“我的→我的求购”或分类页“我的求购”查看答复、刷新进度；未结束需求可撤回，已答复/不受理/撤回后不继续操作。
5. 管理员“用户求购”查询/筛选状态，选择需求后填写答复，确认账号密码二次验证，再处理。可先开始处理或直接完成答复/暂不受理。权限、版本冲突与审计不可绕过。
6. 商家沿用商品/订单/发票等现有入口，不接收求购广播，也没有管理员求购处理权限。现有订单/客服/售后及当前粮提醒保留；本轮不增加活动、降价或求购运营通知。

沿用参考照片、奶油底与深绿配色、圆角和按钮动效。开发包带后端/三端构建及运行时，源码包不含凭据/数据库；升级V025保留既有数据。专用.pilot和本机备份属于私有资料，不放入交付ZIP，不分享测试账号窗口截图。

真实渠道、真实资金交易、正式定位导航、生产容量、Android实机专项与生产总验收仍未完成；本批只验收本机模拟工程功能。其他V1差距见原始需求收尾复核，不启动V2/V3。
