# Pawday V1 安全维护版启动说明

版本：1.0.7-engineering，专用本机模拟测试环境。

1. 双击桌面“PawdayV1”图标。启动时会等待Docker和四服务，健康后打开`http://127.0.0.1:4172`。首次构建补丁镜像可能需要较长时间；不要反复启动。
2. 入口内选择消费者、商家或管理员。原测试账号保持不变，通过本机“测试账号”窗口查看；消费者短信仍模拟，不分享该窗口截图。网页用Ctrl+F5刷新构建。
3. 管理员/商家沿用账号密码；管理员“用户求购”可密码二次验证答复，消费者在“我的求购”查看。筛选、排序、订单、售后等既有流程保留。
4. 若Docker系统组件本身损坏，启动器会显示原因。可重启Docker Desktop后重试；不要使用Factory Reset、删除volume或重新初始化测试账号来绕过问题。
5. 本批会恢复仅属于此安装目录的失败进程。其他程序占用端口时明确报错，不强行结束其他应用。
6. 关闭浏览器不会关闭后台。需要停机时，在此安装目录执行`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/desktop.ps1 -Action Stop`，保留私有数据与MQ节点身份。

开发包解压到新的目录后，可执行`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/create-desktop-shortcut.ps1 -DeliveryRoot "实际解压目录"`创建快捷方式；整个包必须完整解压，不能单独打开ZIP内脚本。已有桌面PawdayV1无需重新解压或重建账号。

消费者APK沿用0.6.12+18原受验文件以保留签名；本批Flutter仅更新生成DTO的契约校验头，执行逻辑保持一致，不要求重复安装。测试依旧使用合成账号/地址/宠物和模拟供应商，不进行真实扣款、短信、发货或外部AI调用。留白项保持原状。
