# V2.2 家庭共享与照顾协作启动说明

开发环境版本：2.0.2-engineering；消费者Web / Android：2.0.2+22。本阶段延续内部模拟环境，生产准入证据、运营通知继续留白。

## 电脑与安卓入口

更新后的解压目录仍为桌面 `PawdayV1`，双击原 `PawdayV1` 快捷方式启动。消费者 http://127.0.0.1:4175 ，商家 http://127.0.0.1:4273 ，管理员 http://127.0.0.1:4174 。测试账号窗口查看本机登录配置；消费者继续使用原来的唯一账号和密码，不需要短信验证码。源码或开发ZIP不含本机私密凭证、数据库数据和签名私钥。

安卓安装本目录 `Pawday-Consumer-2.0.2-household-debug.apk`。连接电脑、允许USB调试，使用桌面 `Pawday安卓连接` 入口建立8086反向连接，再打开App登录。APK采用已固定的内部测试签名，提供签名校验；如设备仍安装早期临时签名的APK，系统可能拒绝覆盖，先保留需要的测试资料，再自行决定换装。未自动卸载手机App，本轮未进行新APK的实机验收。

## 家庭照顾体验

1. 消费者进入“宠物”，添加自己的测试宠物，再点“家庭照顾”。该页面选择的当前宠物只用于家庭照顾，不改变购物或智能选品使用的主人宠物上下文。
2. 主人点“邀请成员”，核对共享范围，选择“仅查看”或“共同照顾”。邀请凭证24小时有效、首位消费者接受后失效；最多5个未过期邀请、20名有效成员。凭证不要放到URL、截图或公开页面。创建结果关闭后不在邀请列表再次展示凭证；丢失可撤销再新建。
3. 已登录的受邀成员在“接受邀请”粘贴凭证。成员不能编辑或删除主人档案，不能使用私人照片、主人的订单/地址/支付/客服、余粮通知或AI授权。主人也不能接受自己的邀请。
4. 主人和共同照顾成员可以创建照顾任务、确认完成、写喂食/散步/清洁护理/观察记录。取消任务只限主人或创建人；完成/取消后保留事实。记录不可编辑删除；发生冲突先刷新，再核对最新状态。过敏信息未知不代表没有过敏。
5. 主人可以撤销邀请或成员；成员可以退出。撤销或退出同时关闭该宠物所有未使用邀请。权限每次请求重新检查；界面20秒复核、手动刷新和写入失败都会重新核对，身份变化或权限失效清除页面上下文。

## 本阶段测试边界

单一消费者人工测试账号维持原安排。因此本机可人工验证主人创建/撤销邀请、任务和记录；不通过切换真实手机号、开放公众注册来模拟家人。成员接受、跨成员访问、退出、并发和撤销后的拒绝由独立自动化身份在隔离PostgreSQL环境验证。后续需要多人实测时另行确认测试身份安排；当前交付不声称已完成多人现场体验。

宠物列表使用游标分页；概览展示最近100项任务、100条日常记录、50项邀请，界面明确范围。完整事实仍在数据库保留，未启用自动销毁；保留与注销政策仍待业务审核。新环境先完成数据库迁移V027，使用源码中的OpenAPI生成检查和完整CI验证。
