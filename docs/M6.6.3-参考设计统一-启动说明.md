# PawdayV1 三端参考设计版启动说明

版本：1.0.3-engineering；消费者 0.6.9+15。本机模拟工程环境，需 Docker Desktop。

1. 使用原桌面 PawdayV1 图标，或解压完整开发包后双击「启动PawdayV1.cmd」。已启动时刷新页面即可。
2. 桌面入口 http://127.0.0.1:4172；消费者 http://127.0.0.1:4175；商家 http://127.0.0.1:4273；管理员 http://127.0.0.1:4174。已有页面按 Ctrl+F5。
3. 双击「查看测试账号.cmd」查看本轮密码；管理员 local-admin；商家 local-staff-a / local-staff-b。原随机密码保持有效。
4. 消费者使用 +999000000001 至 +999000000020；勾选同意后申请验证码，切回本机账号窗口点击 Refresh local SMS codes，填写该账号最新六位验证码并登录。
5. Android 安装新的 0.6.9 debug APK；USB 连接电脑时执行 adb reverse tcp:8086 tcp:8086，本机服务保持运行。该 APK 的 API 地址为 http://127.0.0.1:8086/api/v1，仅用于本机连接模拟测试。
6. 敏感操作仍需再次输入密码；「停止PawdayV1.cmd」只停止本项目服务，测试数据保留。

三端已按参考统一图片、布局与按钮；图片、中文字体和 GSAP 均随包本地加载。系统减少动态效果时停用位移、旋转和缩放。

开发：pnpm install --frozen-lockfile；pnpm generate:check；pnpm lint；pnpm typecheck；pnpm test；pnpm build。模拟网页构建设置 VITE_PAWDAY_PILOT=true。Flutter 使用随仓库版本的 SDK；flutter pub get --enforce-lockfile；flutter analyze；flutter test；flutter test --dart-define=PAWDAY_PILOT=true test_pilot。Android/Web 构建命令及图片包校验见 .github/workflows/frontend.yml。

14 项生产资料继续留白，M6 生产总验收未关闭。参考图片不代表实际商品实拍。
