# Bundled pilot Chinese font

Noto Sans SC variable font, distributed under the SIL Open Font License 1.1. The unchanged font and complete license are shipped together to render the simulated pilot offline without requesting remote CJK font files.

Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc

Font: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf

License: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt

Only the pilot theme selects `PawdaySans`; ordinary application mode retains its existing theme. Local engineering consumer Web remains a preview rather than a public storefront.
